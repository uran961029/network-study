
물리장비는 가볍게 넘어가기

1. 라우터 : LAN.끼리 연결해서 패킷을 처리하는 장비
	- 현대 인터넷의 핵심이라고 할 수 있는 장비
	  
	- 기본 기능 
		- IP주소를 보고 목적지가 내부 LAN인지 아닌지 확인해서 패킷을 처리
		- LAN과 LAN을 연결하고 목적지에 따라 패킷을 처리
		- 여러 장치로 구성된 네트워크 세그먼트를 LAN으로 묶어 내부 패킷을 처리하면서 동시에 외부 LAN과도 연결해서 상호 간 패킷을 교환 << 이런 패킷 처리를 라우팅이라고 함. 

	- 페킷의 해더를 확인하고 자신이 관리하는 LAN을 향한 패킷이면 받아들이고, 아니면 다른 라우터에 전송 (여기서 다른 라우터 == 자신과 직접 연결된 라우터(이웃 OR 인접 라우터라고 함))
	- 위 기능을 위해서 라우터에는 내부 LAN과 외부 LAN을 연결하는 연결포트가 2개있음
		- 내부 LAN 연결 포트 : LAN 포트, 외부 인터넷 연결 포트 : WAN 포트

	- 라우터와 인터넷의 관계
		- 기본적으로 LAN과 LAN을 연결하여 대규모 LAN이나 인터넷을 구성하는 장치이고, 전용선이나 ISP(Internet Service Provider)의 회선 등을 이용하면 먼 거리의 라우터와 연결할 수 있음.
		- **인터넷**은 이런 원리로 LAN을 광범위하게 연결한 것
		- 포로토콜은 TCP/IP가 기본, 라우터의 WAN쪽에서는 글로벌IP주소 사용 
		- 내부 LAN과 외부 인터넷의 경계에 설치하는 라우터는 에지 라우터라고 함
		  
2. 엑세스 포인트 : 무선 LAN 전파를 모으는 장치
	- 무선 LAN에서 허브에 해당하는 장치로, 무선 LAN을 구축하려고 여러 기기의 무선 연결을 모아서 네트워크에 연결함.
	- IEEE 802.11시리즈 무선 LAN규격(일반적으로 WI-FI)으로, 단말기와 무선 연결을 설정하는 장치.
	  
	- 비슷한 장치로 광대역 라우터와 WI-FI 라우터가 있음. 
	- 시중에서 판매되는 대부분의 라우터는 WIFI 연결 기능을 갖추고 있음.
	- 광대역 라우터와 엑세스 포인트가 통합된것으로 라우터는 3계층 장치(이게 무슨말?)
	- 반면에 엑세스 포인트나 WIFI장비는 2계층 장치


	- 인프라 스트럭처 모드 & 애드혹 모드
		  1. 인프라 스트럭처 모드
			- 무선 LAN에서는 액세스 포인트가 유선 LAN의 L2스위치 역할을 함. 
			- 무선 LAN에 연결되는 장치는 WI-FI모듈을 이용해 액세스 포이트에 연결 -> 액세스 포인트는 세그먼트 내 통신을 제어 

		2. 애드혹 모드 
			- 액세스 포인트를 거치지 않고 장치끼리 직접 무선 링크 기능을 사용해서 통신
			- 컴퓨터와 프린터를 직접 연결할 때 사용

3. 허브(집선 장치) : 여러 회선을 모으는 장치
	1. 다수의 회선을 정리해서 기기 접속을 확보하는 장치
	2. 컴퓨터나 프린터등이 여러대 있는 사무실에서 일반적으로 허브를 이용하여 장비를 연결

	- 리피터와 스위치 기능도 갖춤
		- 허브 뒷면에는 LAN 케이블 연결 포트가 여러개 나열되어 있음.
		- 포트 수만큼 선을 모을 수 있으며, 포트 수는 4,8,16이 일반적.
		- 연결할 장치가 더 많아지면 포트 중 하나를 다른 허브에 연결(캐스케이드 연결)해서 연결대수를 늘릴 수 잇음
		- 이전에는 집선 기능만 가능했었찌만 현재는 아님. 대부분의 허브가 전원이 필요하며, 신호 증폭/ 전파 형성등을 하도록 되어있어서 리피터(신호 증폭 중계기) 기능도 하고, 전자 회로나 CPU를 장착해서 소프트웨어로 이더넷 프레임을 해석하고 연결 전환을 수행하도록 하는 제품이 주류가 됨. 
		- 다만 이런장치는 스위치로 분류되어 엄밀히 말하자면 허브라고 부르지는 않음.
		- 현재 허브는 스위치를 의미하며 순수한 허브와 구분하고자 스위칭 허브라고도 함.

4. 스위칭 허브(스위치) : 회선을 모아서 연결 대상을 전환하는 장치
	1. 스위치는 단순히 회선을 모으는 것 + 연결 대상을 전환하는 기능을 갖춤
	2. 스위치를 이용해서 세그먼트를 분할할 수 있음.
		- 스위치는 원래 2계층에서 연결하는 장치라서 L2스위치라고 함. 
		- 반면에, IP주소에 의한 라우팅 기능을 가진 3계층에 연결하는 스위치를 L3스위치라고 함. 
		- L3스위치는 LAN끼리 연결할 수 있으며, 라우터와 거의 기능이 동일.
		- 라우터와 차이는 L3스위치가 L2스위치의 기능을 갖추면서 하드웨어로 처리하므로 고속인 점, 포트 수가 많은 제품이 있는 점등이 있음.
		- L3스위치는 CPU를 탑재 -> 임의의 포트를 지정해서 세그먼트 나눌 수 있고, 이 기능을 VLAN이라고 함. 
		- VLAN(Virtual LAN) : 세그먼트를 논리적으로 분할해서 여러개로 만들거나, 여러스위치의 세그먼트를 하나의 세그먼트로 논리적으로 묶을 수 있음.
		- -> 임의의 포트 수를 가진 세그먼트를 스위치 한대로 설정할 수 있음. 

	- 2계층에서 연결되는 장치로, 원칙적으로 이더넷 프레임을 처리함. 
	- 회선 내 헤더나 페이로드 정보를 참조해서 목적지의 장치와 연결함. 
	- 스위치를 사용하면 이더넷 프레임의 충돌을 방지하거나 불필요한 이더넷 프레임을 억제할 수 있음.
	- 외관은 허브와 거의 비슷하지만 포트수가 24개나 48개등으로 늘어날때가 많음.
	- 데이터센터등 서버 랙에는 많은 서버나 스토리지등이 들어가며 이런 장치를 스위치로 묶어 네트워크를 구축함. 

5. 케이블과 커넥터
	1. 이외에도 케이블(데이터를 전송하는 회선)과 커넥터(케이블을 이어주는 연결부)가 있지만, 관련도가 적으므로 스킵
