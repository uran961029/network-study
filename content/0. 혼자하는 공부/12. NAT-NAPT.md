LAN 내부에서 사용하는 프라이빗 IP 주소는 인터넷에서는 사용할 수 없는 주소라서, LAN 내부의 컴퓨터가 인터넷에 엑세스하려면 NAT OR NAPT를 사용해서 IP 주소를 변환해야 함.
* NAT(Netwrok Address Translation) / NAPT(Network Address Prot Translation)

1. 인터넷에 연결하려면 글로벌IP주소가 필요함.
2. 일반적으로 LAN 내부 컴퓨터에는 프라이빗 IP 주소만 할당 됨.
3. 그 상태로는 컴퓨터에서 인터넷에 접속할 수 없기때문에, 이 문제를 해결할 방법 중 하나가 NAT 또는 NAPT임(그럼 이 외에는 어떤 방법이 있는데?)
4. NAT 작동 방식
	1. 기업 등에 할당 된 글로벌 IP 주소와 각 장치에 설정된 프라이빗 IP 주소의 일대일 대응 변환표를 작성
	2. 특정 프라이빗 IP주소에서 인터넷으로 액세스 요청이 있으면 변환표를 사용하여 글로벌 IP주소를 해당 통신에 할당 함.
	3. 인터넷에서 할당받은 글로벌 IP주소로 응답이 있으면 대응하는 프라이빗 IP주소의 장치로 IP를 변환해서 통신함.

5. NAPT의 등장
	1. NAT에서는 사용할 수 있는 글로벌 IP주소가 적으면 여러 장치에서 엑세스하기 어려움. 
	2. 이 문제를 해소하고 적은 글로벌 IP 주소를 효율적으로 사용할 수 있게 해주는 기술이 NAPT임.
	3. NAPT에서는 IP 주소 변환표 외에 TCP/UDP의 출발지 포트 번호도 사용 함. 
	4. 동일한 글로벌 IP 주소라도 프라이빗 IP주소마다 다른 포트 번호를 하당하면 어떤 컴퓨터에서 보낸 요청인지, 어떤 컴퓨터에 대한 응답인지 구별 가능
