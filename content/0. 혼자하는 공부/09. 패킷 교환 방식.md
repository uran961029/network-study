
패킷 교환 방식 : 데이터를 분할해서 전송하는 통신 방식
	- 인터넷이나 이더넷을 비롯하여 많은 네트워크에서 채택한 통신 방식
	- 데이터를 패킷이라는 단위로 분할해서 통신

1. 원리와 장점
	1. 패킷이란 : 주고받는 데이터 단위
	데이터는 원래크기로 주고받는게 아니라, 일정한 크기로 분할해서 전송하며, 이 단위를 패킷이라고 함. 
	패킷의 크기는 프로토콜에 따라 정해짐
	
	2. 장점 : 매번 상대방과 회선 연결을 할 필요가 없다는 것.
		- 회선 교환 방식은 상대의 회선을 독점하지만, 패킷 교환 방식은 회선만 연결되어있따면 데이터를 독립적인 타이밍에 송신할 수 있음.
		- 추가로 회선교환 방식은 상대방과 연결을 설정하는 절차가 필요했지만 패킷 교환 방식에서는 그런 절차가 필요하지 않음.
		- 동시에 대량의 데이터를 전송할 수 있으며, 다수의 상대방과 효율적으로 데이터를 송수신할 수 있음.
		- 서로 다른 종류의 패킷(프로토콜)도 혼재할 수 있으며, 연결 일부에 장애가 발생해도 다른 경로로 송수신할 수 있음.
	
	3. 패킷 교환 방식에 필요한 정보
		- 같은 회선 내에 무수한 패킷이 흐르게 되므로, 패킷별로 관리정보가 필요함. 
			1. 출발지와 목적지 정보
			2. 데이터 분할시에 목적지에서 데이터를 재구성하는 정보도 필요
		- 이런 정보들은 헤더에 집약되어 통신 데이터 본체와는 별도로 부여 됨.
