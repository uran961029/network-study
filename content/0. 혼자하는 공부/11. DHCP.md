dhcp(Dynamic Host Configuration Protocol) : lan 내 장치에 ip 주소를 자동으로 할당하는 프로토콜로, dhcp 서버가 이 작업을 처리하지만, 일반적으로는 라우터와 기본 게이트웨이가 담당함.(이 문장이 이 해가 잘 안감. dhcp 서버가 담당하는게 맞는데, 일반적으로 저 두 장치가 담당한다고?)

1. 네트워크에 연결되는 각 장치의 ip 주소는 네트워크 관리자가 설정함. 인터넷에 접속하는 장치에는 글로벌 ip 주소를 설정하지만, lan 내 장치에는 프라이빗 ip 주소를 임의로 할당하게 됨.
2. ip 주소 설정은 각 장치의 설정 화면에서 수동으로도 가능하지만, 효율적이지 않고 실수가 잦을수있어서 dhcp를 이용하여 자동으로 할당함
	1. DHCP는 이 방식과 절차를 규정한 클라이언트 서버형 프로토콜
		- 클라이언트 서버형 : 컴퓨터 사용 형태 중 하나, 특정 처리를 전문으로 하는 컴퓨터를 서버라고 하고 서버에 엑세스해서 서비스를 이용하는 컴퓨터를 클라이언트라고 함. (그럼 이 말은 클라이언트 - 서버형이라고 양측이 존재한다고해서 클라이언트 서버형이라는거야?)
	2. DHCP 서버는 클라이언트의 요청에 따라 관리하는 IP주소 중 적절한것을 할당함. 클라이언트는 할당받은 정보로 자신의 설정 정보를 업데이트함.
	3. DHCP 서버용 프로그램은 라우터, 고기능 스위치, 리눅스 OR 윈도우 서버 등에 준비되어 있고, DHCP 클라이언트용 프로그램은 윈도우, MAC OS , 리눅스, 안드로이드, IOS등 주요 OS에 설치되어있음.
	4. IP 주소 자동 할당 절차 = D.O.R.A
