인터넷은 전 세계 LAN을 연결한 것이라고 할 수 있음. 방대한 양의 패킷을 처리하려면 목적지 지정 뿐 아니라 경로를 제어하는 라우팅이라는 기술이 필요함. 

1. 경로를 제어하는 라우팅
	1. 라우터의 기본 기능은 패킷을 참조해서 자신이 관리하는 LAN으로 들어오는 패킷은 받아들이고, 그렇지 않으면 다른 라우터로 전달하는 것. 
	2. 라우터 역할에는 안과 밖의 교통 정리 외에도 어떤 라우터를 경유하여 패킷이 목적지까지 도달하는지 같은 경로(루트) 제어도 있음.
	3. 경로를 제어할 수 ㅇㅆ으면 경유하는 라우터 수를 최소화하거나 고장 난 라우터를 우회할 수 있음. 
	4. 회선 속도나 요금을 판단해서 최단 경로나 최저 요금을 경로로 제어할 수도 있음.
	5. 이런 경로 정보를 메트릭이라고 하며, 메트릭 및 목적지 라우터 정보는 라우팅 테이블이라는 표로 관리됨.

2. 라우팅 프로토콜
	1. 라우터 간 경로를 제어하고자 정보를 교환하는 프로토콜을 라우팅 프로토콜이라고 함. 
	2. IGP(Interior Gateway Protocol) : **동일한 관리 정책의 라우터(AS: Autonomous System)** 끼리 경로를 제어하는 프로토콜
		1. 동일한 관리 정책으로 동작하는 라우터는 AS 번호라는 식별자로 구분
		2. AS번호는 일반적으로 통신 사업자 및 공급자별로 할당 됨.
		3. LAN 내부/외부 모두 대상이 됨(엥 IGP는 하나의 랜 내에서만 해당되는거 아님?)
	3. EGP(Exterior Gateway Protocol) : AS의 라우팅 정보를 교환하는 프로토콜
	4. 라우팅 프로토콜은 라우팅 정보의 취급 방법과 동작 방식에 따라 거리 벡터형, 링크 스테이션형, 하이브리드형, 경로 벡터형으로 나눌 수 있음(넷다 도식화해서 보여주고 종류도 설명)
